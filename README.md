# 🌸 다써바 (DASSEOBA) 화장품 쇼핑몰 + Supabase DB 연동

> **iamcap.com 스타일 3단 메가 네비게이션 & K-뷰티 E-커머스 플랫폼**  
> 1+1 특별 기획전, 쿠폰/포인트 복합 결제, 피부타입별 맞춤 추천 & 포토 리뷰, 24시간 AI 뷰티 챗봇, 올인원 관리자 ERP (발주, 재고, 원부자재, 전자세금명세서, 배송관리)

---

## 🚀 프로젝트 주요 기능

### 1. iamcap 스타일 네비게이션 & UI/UX
* **최상단 이벤트 띠배너**: 1+1 프로모션 및 '오늘 하루 보지 않기' 쿠키 연동
* **탑 유틸 바**: 로그인/가입, 주문조회, 최근본상품, 고객센터 드롭다운
* **3단 계층형 메가 GNB**: BEST / 신상품 / 1+1 기획전 / 스킨케어 / 클렌징 / 선케어 / 메이크업 / 옴므
* **슬라이드 다운 퀵 검색**: 최근 검색어 및 실시간 인기 뷰티 검색어
* **모바일 슬라이드 드로어**: 3단 아코디언 카테고리 + 커뮤니티 탭 전환
* **모바일 하단 플로팅 탭바**: 카테고리 / 검색 / 홈 / 마이 / 장바구니 / Top 버튼
* **PC 우측 플로팅 퀵메뉴**: 최근 본 화장품 롤링 썸네일, 카카오톡 1:1 상담 바로가기, AI 챗봇

### 2. 쇼핑 및 커머스 핵심 기능
* **1+1 타임특가 기획전**: 실시간 카운트다운 타이머 및 본품 무료 더블 증정
* **상품 상세 5단 탭**: 상세정보, 전성분 & 기능성 고시, 포토 리뷰(피부타입 필터), Q&A, 배송/반품 규정
* **장바구니**: 1+1 혜택 자동 계산, 30,000원 무료배송 달성 프로그레스 바, 선택 삭제/주문
* **주문 & 결제 (Checkout)**: 쿠폰 할인, 포인트 결제 (최대 50%), PG 간편결제(카카오/네이버/토스/카드), 현금영수증/전자세금계산서 발행 신청
* **마이페이지**: 5단계 주문/배송 트래커, 나의 주문/취소/환불/반품 내역, 찜 목록, 포인트 내역, 쿠폰함, 1:1 문의

### 3. 커뮤니티 및 고객센터
* **게시판 4종**: 공지사항, 뷰티 꿀팁 자유게시판, 상품 Q&A (비밀글 지원), 1:1 피부정밀진단 & 클래스 예약 확인 게시판
* **고객센터**: 카테고리별 FAQ 아코디언, 카카오톡 상담원 채널 연동
* **24시간 AI 뷰티 어드바이저 챗봇**: 피부타입 맞춤 화장품 추천, 주문/배송 안내, 카카오톡 상담원 원클릭 연결

### 4. 올인원 통합 관리자 ERP (`/admin`)
* **대시보드**: 실시간 총 매출, 결제완료 발주대기 건수, 안전재고 부족 알림
* **회원 관리**: 회원 목록 검색, 회원 등급제 (WELCOME~VIP), 포인트 수동 지급/차감
* **상품 관리**: 상품 등록/수정/삭제, 1+1 행사 설정, 옵션 및 재고 관리, 전성분 입력
* **주문/발주 관리**: 신규 주문 확인, 일괄 배송준비 처리, **발주서 엑셀(CSV) 다운로드**
* **배송 & 송장 관리**: 택배사 선택, 송장번호 입력 및 즉시 출고 처리
* **재고 & 원부자재 관리**: 완제품 재고 + 용기, 캡, 단상자, 원료, 완충재 입출고 수량 조절
* **전자세금명세서 관리**: 현금영수증 및 전자세금계산서 신청 승인/반려, 인쇄 지원
* **팝업 & 이벤트 관리**: 메인 팝업 활성화 토글 및 기간 설정

## 🌐 Supabase 데이터베이스 연결 설정

1. [Supabase](https://supabase.com) 프로젝트를 생성합니다.
2. `supabase/schema.sql` 파일의 SQL 스크립트를 Supabase SQL Editor에서 실행합니다.
3. 프로젝트 루트에 `.env.local` 파일을 생성하고 환경변수를 입력합니다:

```ini
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

*환경변수를 설정하지 않은 경우에도 로컬 스토리지 기반의 스마트 목(Mock) 모드로 모든 기능이 100% 정상 작동합니다.*

## 🚀 Vercel 배포 가이드

1. 프로젝트를 GitHub 리포지토리에 푸시합니다:
```bash
git add .
git commit -m "feat: complete Dasseoba cosmetics shopping mall"
git remote add origin https://github.com/your-username/dasseoba-shop.git
git push -u origin main
```
2. [Vercel](https://vercel.com)에 로그인 후 GitHub 리포지토리를 Import합니다.
3. 필요 시 환경 변수를 등록하고 **Deploy**를 클릭하면 즉시 전 세계 엣지 네트워크에 배포됩니다.
